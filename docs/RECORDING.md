# Как записать демо конвейера

Рецепт записи GIF/видео для README. Один раз подготовили — можно переиспользовать.

## 1. Подготовка терминала

```powershell
cd C:\Users\user\source\repos\langchain-bft-agent
chcp 65001 >$null
.venv\Scripts\activate
```

Требования к окну:
- **Windows Terminal** (не conhost) — корректный UTF-8 для кириллицы.
- Окно **~120 колонок × 35 строк**, шрифт **14–15 pt** (в уменьшенном GIF текст останется читаемым).
- Запись в **1280×720 (720p)**.

## 2. Команда для записи

```powershell
python pipeline.py --task "Добавить отказ от смены «Не могу прийти» и подбор замены" --rules rules.example.txt --max-iters 2 --out nbc_demo.rst
```

Для короткой версии (один проход без второго цикла) — `--max-iters 1`.

## 3. Сценарий (~90 сек после обрезки)

| # | Что на экране | Тайминг |
|---|---|---|
| 1 | Команда запуска + панель «Задача» | 0–10 с |
| 2 | Панель «Правила критика» | 10–15 с |
| 3 | `── Итерация 1: генератор — документ N симв.` | 15–20 с |
| 4 | Панель «Тестировщик (12 правил)» → 12/12 | 20–30 с |
| 5 | `⏳ Критик оценивает документ…` (паузу вырезать) | — |
| 6 | Панель «Критик» — рецензия с severity и «как чинить» | 35–55 с |
| 7 | `Сохранено … в output\nbc_demo.rst` | 55–60 с |
| 8 | `Get-Content output\nbc_demo.rst -TotalCount 25` | 60–75 с |

Ключевой кадр — **п. 6** (рецензия критика): это главный «вау-момент».

## 4. Запись и экспорт

- Инструмент: **ScreenToGif** (регион экрана → GIF) или **OBS Studio** (MP4 → конвертация в GIF).
- Экспорт GIF: **FPS 10–15**, длительность 60–90 сек, итог **до 5 МБ**.
- Вырезать паузу ожидания критика (п. 5).

## 5. Куда положить и вставить в README

```powershell
New-Item -ItemType Directory -Force docs | Out-Null
# положить demo.gif в docs/
```

В `README.md` заменить плейсхолдер:

```markdown
![Демо конвейера](docs/demo.gif)
```

## Совет

Перед записью прогнать один раз без записи — прогреть и убедиться, что вывод чистый (без ошибок).
